# Diggaj Niraula — Portfolio

A responsive portfolio in plain HTML, CSS and JavaScript. Open `index.html` directly, or serve the folder with any static web server. No installation or build step is required.

## Editing
- `index.html`: biography, projects, experience, education and contact links.
- `styles.css`: colors, typography, layout and responsive rules.
- `script.js`: portrait scroll zoom, section reveals, navigation and reading progress.
- `assets/profile.jpg`: original portrait; `assets/gokart.jpg`: original project photograph.

Career details were retained from the previous portfolio; unsupported performance claims, grade commentary and informal anecdotes were removed. LinkedIn could not be independently reviewed. Confirm dates and current education status when updating the site.

## Interaction and accessibility
Normal browser scrolling is preserved. The portrait zooms on scroll; sections fade into view. Reduced-motion settings disable these effects. Content remains visible without JavaScript. The mobile menu supports Escape, and project summaries use native disclosure controls. Contact links open email or the linked profile; no backend is needed.

The original CNAME and favicon are preserved.
