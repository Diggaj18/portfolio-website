# Diggaj Niraula — Interactive Portfolio

Plain HTML, CSS and JavaScript. Open `index.html` directly or serve this folder using any static web host. No package installation, build process, API keys or browser plugins are required.

## The interactive experience
- A continuously rotating 3D particle sphere and orbital paths, projected with Canvas 2D.
- Drag an empty area of the hero on desktop to rotate the field. The “Pulse the field” button sends out an animated wave.
- A floating portrait, pointer-responsive image tilt, magnetic links and scroll-driven portrait zoom and name movement.
- A continuously moving typography strip.
- A pinned, horizontally scrolling project gallery on sufficiently large desktop viewports. Arrow controls also navigate the projects.
- A touch-scrollable project gallery on tablets and phones, with arrow buttons as an alternative to swiping.
- Scroll-triggered section reveals, active experience markers and an education-image parallax effect.
- A motion control that pauses the animation and remembers the preference locally. Operating-system reduced-motion preferences are respected.

All biography and project content is present in the HTML. Navigation, native project disclosures and contact links work without JavaScript. With animation disabled, projects remain available as ordinary content or a horizontally scrollable mobile gallery. Animation stops while the browser tab is hidden.
